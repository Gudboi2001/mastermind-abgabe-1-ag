MASTERMIND - REST API CHANGELOG
===============================================
Fortlaufende Versionierung. Jede Abgabe ergänzt die vorherige und bleibt
abwährtskompatibel (nur additive Änderungen). Basis-Pfad: /api/v1
Legende:  +  neuer Endpunkt/Feld     ~  geändert
===============================================

  + GET  /health
  + POST /games                 -> {gameId, codeLength, colors}
  + GET  /games/{id}            -> Spielzustand (ohne Lösung)
  + POST /games/{id}/guesses    Body {guess:[4 Farben]} -> {attempts, black, white, solved}
        black = Farbe+Position richtig, white = Farbe richtig/Position falsch
